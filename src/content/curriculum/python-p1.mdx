## 2. Variabel Sebagai *Name Binding* (Bukan Kotak Statis)

Di Python, variabel bukanlah "kotak" yang dipatok dengan tipe kaku di memori, melainkan sebuah **label nama** (*name binding*) yang ditempelkan pada objek data di *heap*.

<CodePlayground
  client:load
  language="python"
  title="Latihan P1.2: Dynamic Name Binding"
  initialCode={`pesan = "Halo belajar.in"
print("Tipe awal:", type(pesan).__name__)

# Variabel yang sama dapat diikatkan ke objek tipe lain
pesan = 42
print("Tipe baru:", type(pesan).__name__)
print("Nilai pesan:", pesan)`}
  expectedOutput={`Tipe awal: str\nTipe baru: int\nNilai pesan: 42`}
/>

## 6. Mini Proyek P1: Evaluasi Simulator Tebak Logika

Mari kita gabungkan fungsi, perulangan `for`, penanganan kondisi, dan koleksi data ke dalam program terpadu.

<CodePlayground
  client:load
  language="python"
  title="Mini Proyek P1: Evaluasi Tebak Target"
  initialCode={`def uji_tebakan(target, tebakan):
    hasil = []
    for t in tebakan:
        if t == target:
            hasil.append(f"Tebakan {t}: Tepat Sasaran!")
            break
        elif t < target:
            hasil.append(f"Tebakan {t}: Terlalu Rendah.")
        else:
            hasil.append(f"Tebakan {t}: Terlalu Tinggi.")
    return hasil

target_rahasia = 42
daftar_tebakan = [20, 50, 42]

for baris in uji_tebakan(target_rahasia, daftar_tebakan):
    print(baris)`}
  expectedOutput={`Tebakan 20: Terlalu Rendah.\nTebakan 50: Terlalu Tinggi.\nTebakan 42: Tepat Sasaran!`}
/>
