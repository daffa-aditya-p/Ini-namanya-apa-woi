## 2. KONSEP INTI: Fondasi Sintaks & Dynamic Name Binding

Berdasarkan panduan resmi [Python 3.12 Documentation](https://docs.python.org/3/tutorial/introduction.html) dan [W3Schools Python Tutorial](https://www.w3schools.com/python/), lima prinsip utama Python meliputi:

1. **Keterbacaan Kode di Atas Segalanya (*The Zen of Python* - PEP 20):**
   - *"Readability counts."* Kode dibaca jauh lebih sering daripada ditulis.
   - Sintaks Python membuang titik-koma (`;`) dan kurung kurawal (`{}`) untuk meminimalkan beban kognitif mata pembaca.
2. **Indentasi 4 Spasi Baku (PEP 8):**
   - Indentasi bukan sekadar gaya penulisan (*beautifier*), melainkan penentu struktur blok logika resmi.
   - Gunakan selalu 4 spasi untuk setiap tingkatan blok percabangan (`if`) atau perulangan (`for`).
3. **Variabel Sebagai *Dynamic Name Binding*:**
   - Variabel dibuat saat pertama kali diberi nilai (*assignment* via `=`).
   - Tipe data melekat pada nilai objek di memori, bukan pada nama variabelnya.
4. **Operator Aritmatika Presisi:**
   - Pembagian Riil (`/`): Selalu menghasilkan tipe desimal `float` (misal: `17 / 5` menghasilkan `3.4`).
   - Pembagian Bulat (*Floor Division* `//`): Menghasilkan pembulatan ke bawah menuju bilangan bulat terdekat (misal: `17 // 5` menghasilkan `3`).
   - Modulus (`%`): Menghasilkan sisa bagi pembagian bulat.
   - Eksponensial (`**`): Menghitung pemangkatan angka secara efisien.
5. **Format String Modern (*f-strings* - PEP 498):**
   - Menggunakan prefiks `f"..."` dengan ekspresi yang dibungkus `{ekspresi}` untuk merangkai teks secara cepat dan ekspresif.

## 6. KESALAHAN UMUM (COMMON MISCONCEPTIONS)

1. **Miskonsepsi Mencampur Spasi dan Tab:** Mencampurkan tombol Spasi dan Tab dalam satu blok kode memicu `IndentationError: unindent does not match any outer indentation level`. Standar PEP 8 mewajibkan penggunaan tepat 4 spasi murni.
2. **Miskonsepsi Lingkup Variabel Loop `for`:** Berbeda dari bahasa C atau Java di mana variabel loop terisolasi di dalam blok `for`, di Python variabel loop tetap hidup dan dapat diakses setelah perulangan selesai dalam scope fungsi yang sama.
3. **Miskonsepsi Operator Pembagian:** Mengira `4 / 2` menghasilkan integer `2`. Di Python 3, operator `/` selalu mengembalikan float (`2.0`). Jika kamu menginginkan integer, gunakan `4 // 2`.
4. **Miskonsepsi Argumen Bawaan yang Dapat Diubah (*Mutable Default Argument*):** Menulis `def fungsi(data=[])` berbahaya karena list default dibuat hanya sekali saat fungsi pertama kali didefinisikan, bukan setiap kali dipanggil. Gunakan `data=None` lalu inisialisasi di dalam badan fungsi.
