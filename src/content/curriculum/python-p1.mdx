## Sub-bab 1.1: Cetak Pertama & Hello World

Langkah paling fundamental dalam pemrograman adalah menampilkan informasi ke layar melalui *Standard Output* (`stdout`). Di Python, fungsi bawaan `print()` adalah jendela komunikasimu dengan dunia luar.

Fungsi `print()` menerima satu atau banyak argumen yang dipisahkan dengan koma. Secara bawaan, Python menyisipkan satu karakter spasi di antara tiap argumen (`sep=" "`) dan mengakhiri cetakan dengan baris baru (`end="\n"`).

## Sub-bab 1.2: Variabel & Tipe Primitif

Di Python, variabel tidak dideklarasikan dengan tipe data kaku seperti `int x` atau `let x`. Variabel otomatis tercipta saat pertama kali kamu memberinya nilai (*assignment* melalui operator `=`).

Empat tipe data primitif utama di Python meliputi:
1. **`int` (Integer):** Bilangan bulat dengan presisi tak terbatas (misal: `42`, `-7`).
2. **`float` (Floating Point):** Bilangan desimal presisi ganda IEEE 754 (misal: `3.14`, `-0.5`).
3. **`str` (String):** Rangkaian karakter teks ber-encoding UTF-8 (misal: `"belajar.in"`).
4. **`bool` (Boolean):** Nilai kebenaran biner: `True` atau `False` (huruf kapital di awal).

## Sub-bab 1.3: Operator & Ekspresi

Python menyediakan operator aritmatika lengkap dengan perbedaan semantik yang sangat penting:
- **Penjumlahan (`+`) & Pengurangan (`-`)**
- **Perkalian (`*`)**
- **Pembagian Riil (`/`):** Selalu menghasilkan bilangan desimal (`float`), bahkan jika kedua bilangan habis dibagi (`4 / 2` menghasilkan `2.0`).
- **Pembagian Bulat (*Floor Division* `//`):** Membulatkan hasil bagi ke bawah menuju bilangan bulat terdekat (`7 // 2` menghasilkan `3`).
- **Sisa Bagi (*Modulo* `%`):** Mengembalikan sisa pembagian bilangan bulat (`7 % 2` menghasilkan `1`).
- **Eksponensial (`**`):** Menghitung pemangkatan (`2 ** 8` menghasilkan `256`).

## Sub-bab 1.4: Input Pengguna & Konversi Tipe

Fungsi `input()` membaca masukan dari pengguna sebagai teks berformat `str`. Untuk memproses nilai tersebut sebagai angka, kita harus melakukan *Type Casting* eksplisit menggunakan fungsi konstruktor seperti `int("42")` atau `float("3.14")`.

Untuk merangkai teks hasil komputasi, Python modern memperkenalkan **f-strings** (*Formatted String Literals*, PEP 498). Awali string dengan huruf `f`, lalu letakkan variabel atau ekspresi komputasi di dalam tanda kurung kurawal `{variabel}`.
