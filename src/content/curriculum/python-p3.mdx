## 2. KONSEP INTI: Pilar OOP & Anatomi Kelas Python

Berdasarkan standar resmi [Python 3.12 Documentation: Classes](https://docs.python.org/3/tutorial/classes.html) dan tutorial praktis [W3Schools Python OOP](https://www.w3schools.com/python/python_classes.asp), empat konsep kunci yang menjadi fondasi Level P3:

1. **Class, Instance, dan Parameter `self`:**
   - `self` mewakili instance objek yang sedang aktif. Python mewajibkan `self` ditulis eksplisit pada pendefinisian method agar relasi atribut transparan.
2. **Enkapsulasi & Dekorator `@property`:**
   - Gunakan awalan `_variabel` untuk menandai atribut terproteksi (konvensi) dan proteksi validasi via getter/setter `@property`.
3. **Dunder (Double Underscore / Magic) Methods:**
   - `__init__`: Konstruktor inisialisasi instance.
   - `__eq__`: Logika kesetaraan perbandingan `==`.
   - `__lt__`: Logika perbandingan lebih kecil `<` (memungkinkan fungsi `sort()` bekerja otomatis).
4. **Modern Data Modeling: `@dataclass`:**
   - Sejak Python 3.7 (PEP 557), dekorator `@dataclass` otomatis menghasilkan `__init__`, `__repr__`, dan `__eq__` tanpa boilerplate manual. Gunakan `frozen=True` untuk menjamin immutability.

## 6. KESALAHAN UMUM (COMMON MISCONCEPTIONS)

1. **Jebakan Argumen Bawaan Mutable (*Mutable Default Argument*):** Menulis fungsi `def tambah(item, keranjang=[])`. Di Python, nilai parameter bawaan dievaluasi **hanya sekali** saat definisi fungsi dimuat ke memori (waktu kompilasi modul). Akibatnya, setiap pemanggilan fungsi tanpa argumen kedua akan memanipulasi objek list yang sama persis di memori. Solusinya: gunakan `keranjang=None` dan inisialisasi `if keranjang is None: keranjang = []` di dalam tubuh fungsi.
2. **Lupa Parameter `self` pada Instance Method:** Menulis `def ambil_nama(): return self.nama`. Saat fungsi dipanggil via objek `m.ambil_nama()`, Python secara implisit meneruskan objek `m` sebagai argumen pertama. Jika method tidak memiliki parameter `self`, interpreter akan melempar `TypeError: takes 0 positional arguments but 1 was given`.
3. **Mengabaikan `super().__init__()`:** Pada class turunan yang meng-override `__init__`, melupakan pemanggilan `super().__init__(...)` akan menyebabkan inisialisasi class induk terlewati. Hal ini menyebabkan error atribut tidak ditemukan (*AttributeError*) saat method turunan dijalankan.
4. **Ilusi Immutability Struktur Bersarang pada `@dataclass(frozen=True)`:** Mengira bahwa `frozen=True` melindungi seluruh data secara mendalam (*deep immutable*). Jika salah satu atribut dataclass adalah `list` atau `dict`, item di dalam list tersebut masih dapat diubah via `append()` atau mutasi indeks! Gunakan tipe `tuple` atau `frozenset` untuk data koleksi pada dataclass beku.
