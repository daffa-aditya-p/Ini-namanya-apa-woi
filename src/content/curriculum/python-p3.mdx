## Sub-bab 3.1: List & Slicing

List adalah deret data berurutan (*ordered*) yang dapat dimutasi (*mutable*) dan mengizinkan elemen duplikat. List diapit dengan kurung siku `[]`.

Teknik paling ampuh untuk memanipulasi list adalah **Slicing** dengan notasi `list[start:stop:step]`:
- `start`: indeks awal pengambilan (inklusif).
- `stop`: indeks batas akhir (eksklusif).
- `step`: interval lompatan (positif untuk maju, negatif untuk mundur/membalik data).

## Sub-bab 3.2: Tuple & Immutability

Tuple adalah deret data berurutan yang bersifat **immutable** (tidak dapat diubah, ditambah, atau dihapus setelah dibuat). Tuple diapit dengan tanda kurung biasa `()`.

Karena sifatnya yang tidak berubah, Tuple lebih hemat alokasi memori dibandingkan List, aman dari mutasi tanpa sengaja, dan dapat dijadikan sebagai kunci di Dictionary.

## Sub-bab 3.3: Dictionary & Hash Map

Dictionary adalah pemetaan pasangan kunci dan nilai (*key-value pairs*) yang diapit oleh kurung kurawal `{kunci: nilai}`. Pencarian nilai berdasarkan kunci berjalan sangat cepat ($O(1)$ amortized).

Sejak Python 3.9+, kita dapat menggabungkan dua dictionary secara bersih menggunakan operator pipa (`|`). Jika terdapat kunci yang sama, nilai dari dictionary sisi kanan yang akan digunakan.

## Sub-bab 3.4: Set & Himpunan

Set adalah kumpulan elemen **tanpa urutan** dan **tanpa duplikasi**. Jika kamu memasukkan nilai yang sama berulang kali, set otomatis hanya menyimpan satu salinan unik.

Set mendukung operasi matematika himpunan secara alami:
- **Union (`|`):** Menggabungkan semua anggota unik dari kedua himpunan.
- **Intersection (`&`):** Mengambil anggota yang ada di kedua himpunan sekaligus.
- **Difference (`-`):** Mengambil anggota himpunan pertama yang tidak ada di himpunan kedua.

<CodePlayground

## 6. KESALAHAN UMUM (COMMON MISCONCEPTIONS / JEBAKAN UMUM)

1. **Mutasi In-Place vs Mengembalikan Koleksi Baru:**
   Pemula sering menulis `hasil = data.sort()`. Method `.sort()` memodifikasi list secara langsung di memori (*in-place*) dan mengembalikan nilai `None`. Jika kamu membutuhkan salinan list baru yang terurut tanpa merusak data aslinya, gunakan fungsi bawaan `hasil = sorted(data)`.
2. **Menggunakan Objek Mutable Sebagai Kunci Dictionary atau Anggota Set:**
   Kunci pada Dictionary dan elemen pada Set wajib bersifat *hashable* (nilai hash-nya tidak pernah berubah sepanjang program berjalan). Mencoba menggunakan `list` sebagai kunci kamus akan langsung memicu `TypeError: unhashable type: 'list'`. Gunakan `tuple` jika kamu memerlukan koleksi sebagai kunci!
3. **Memodifikasi List Saat Sedang Diiterasi:**
   Melakukan `data.remove(x)` atau `data.pop()` di dalam perulangan `for x in data:` akan menggeser indeks elemen internal sehingga Python melewatkan beberapa item. Jika ingin menyaring elemen, gunakan *list comprehension* atau iterasi salinannya `for x in list(data):`.
4. **Membaca Kunci Kamus yang Belum Pasti Ada:**
   Menulis `data["kunci"]` langsung akan melempar `KeyError` jika kunci tersebut tidak ditemukan. Selalu biasakan menggunakan `.get(kunci, nilai_cadangan)` agar program tetap berjalan aman dan andal.
