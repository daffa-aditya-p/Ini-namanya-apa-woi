## Sub-bab 5.1: Class & Object

Class adalah cetak biru (*blueprint*) yang mendefinisikan atribut (data) dan method (perilaku). Object adalah perwujudan konkret (*instance*) dari class tersebut yang hidup di memori.

Method spesial `__init__` bertindak sebagai konstruktor inisialisasi yang dipanggil secara otomatis saat objek baru dibuat:

<CodePlayground
  client:load
  language="python"
  title="Latihan 5.1: Definisi Class dan Konstruktor __init__"
  initialCode={`class Kendaraan:
    def __init__(self, merk: str, kecepatan_maks: int):
        self.merk = merk
        self.kecepatan_maks = kecepatan_maks
        self.kecepatan_saat_ini = 0

    def akselerasi(self, tambahan: int):
        self.kecepatan_saat_ini = min(self.kecepatan_maks, self.kecepatan_saat_ini + tambahan)
        return self.kecepatan_saat_ini

mobil = Kendaraan("Toyota", 180)
print(f"Kendaraan: {mobil.merk} | Kecepatan Awal: {mobil.kecepatan_saat_ini} km/h")
mobil.akselerasi(60)
print(f"Setelah Akselerasi: {mobil.kecepatan_saat_ini} km/h")`}
  expectedOutput={`Kendaraan: Toyota | Kecepatan Awal: 0 km/h\nSetelah Akselerasi: 60 km/h`}

## Sub-bab 5.2: Atribut & Method self

Mengapa setiap method di Python menerima parameter `self` di posisi pertama? Karena `self` adalah pointer referensi eksplisit ke objek instance yang sedang memanggil method tersebut. Saat kamu menulis `mobil.akselerasi(60)`, Python menerjemahkannya menjadi `Kendaraan.akselerasi(mobil, 60)`.

Kita juga harus membedakan:
- **Atribut Instance (`self.nama`):** Melekat pada tiap instance objek secara unik.
- **Atribut Class (`jumlah_karyawan = 0`):** Melekat pada class itu sendiri dan nilainya dibagi bersama oleh seluruh instance.

<CodePlayground
  client:load
  language="python"
  title="Latihan 5.2: Atribut Class vs Atribut Instance"
  initialCode={`class Karyawan:
    jumlah_karyawan = 0

    def __init__(self, nama: str, divisi: str):
        self.nama = nama
        self.divisi = divisi
        Karyawan.jumlah_karyawan += 1

k1 = Karyawan("Rina", "Teknologi")
k2 = Karyawan("Doni", "Pemasaran")
print(f"Karyawan 1: {k1.nama} ({k1.divisi})")
print(f"Karyawan 2: {k2.nama} ({k2.divisi})")
print("Total Karyawan Terdaftar:", Karyawan.jumlah_karyawan)`}
  expectedOutput={`Karyawan 1: Rina (Teknologi)\nKaryawan 2: Doni (Pemasaran)\nTotal Karyawan Terdaftar: 2`}

## Sub-bab 5.3: Pewarisan & super()

Pewarisan (*Inheritance*) memungkinkan subclass mewarisi atribut dan method dari superclass induknya, mencegah pengulangan logika.

Gunakan fungsi `super().__init__(...)` untuk memanggil konstruktor milik kelas induk secara bersih dan aman:

<CodePlayground
  client:load
  language="python"
  title="Latihan 5.3: Pewarisan dan Pendelegasian super()"
  initialCode={`class AkunBank:
    def __init__(self, nomor_rekening: str, saldo_awal: int):
        self.nomor = nomor_rekening
        self.saldo = saldo_awal

    def setor(self, jumlah: int):
        self.saldo += jumlah
        return self.saldo

class TabunganBunga(AkunBank):
    def __init__(self, nomor_rekening: str, saldo_awal: int, bunga_tahunan: float):
        super().__init__(nomor_rekening, saldo_awal)
        self.bunga = bunga_tahunan

    def terapkan_bunga(self):
        nominal_bunga = int(self.saldo * self.bunga)
        self.saldo += nominal_bunga
        return self.saldo

rek = TabunganBunga("ID-00123", 1000000, 0.05)
rek.setor(200000)
saldo_akhir = rek.terapkan_bunga()
print(f"Rekening {rek.nomor} Saldo Akhir: Rp{saldo_akhir:,}")`}
  expectedOutput={`Rekening ID-00123 Saldo Akhir: Rp1,260,000`}
/>

## Sub-bab 5.4: Enkapsulasi @property & Dunder

Enkapsulasi melindungi status internal objek dari modifikasi sembarangan:
1. **Konvensi Internal (`_nama`):** Menandai atribut yang tidak boleh disentuh langsung dari luar class.
2. **Dekorator `@property`:** Mengakses method getter seperti membaca atribut biasa (`dompet.saldo`).
3. **Dekorator `@saldo.setter`:** Memvalidasi data baru sebelum disimpan ke memori.

<CodePlayground
  client:load
  language="python"
  title="Latihan 5.4: Enkapsulasi Validasi dengan @property dan Setter"
  initialCode={`class DompetDigital:
    def __init__(self, nama_pemilik: str, saldo_awal: int = 0):
        self.pemilik = nama_pemilik
        self._saldo = max(0, saldo_awal)

    @property
    def saldo(self) -> int:
        return self._saldo

    @saldo.setter
    def saldo(self, nilai_baru: int):
        if nilai_baru < 0:
            raise ValueError("Saldo tidak boleh negatif")
        self._saldo = nilai_baru

dompet = DompetDigital("Fajar", 50000)
print(f"Pemilik: {dompet.pemilik} | Saldo: Rp{dompet.saldo:,}")
dompet.saldo = 75000
print(f"Saldo Terkini: Rp{dompet.saldo:,}")`}
  expectedOutput={`Pemilik: Fajar | Saldo: Rp50,000\nSaldo Terkini: Rp75,000`}
/>

Python juga memiliki **Dunder Methods** (*Double Underscore* / Magic Methods) untuk mengintegrasikan class kustom dengan fungsi bawaan Python seperti `str()`, `len()`, dan operator `==`:
- `__str__`: Representasi teks ramah pengguna saat dicetak.
- `__len__`: Menentukan panjang objek saat dipanggil via `len(obj)`.
- `__eq__`: Operator kesamaan `==` antar dua objek.

<CodePlayground
  client:load
  language="python"
  title="Latihan 5.5: Magic Dunder Methods (__str__, __len__, __eq__)"
  initialCode={`class KeranjangBelanja:
    def __init__(self, nama_pembeli: str):
        self.pembeli = nama_pembeli
        self.items: list[str] = []

    def tambah(self, item: str):
        self.items.append(item)

    def __len__(self) -> int:
        return len(self.items)

    def __str__(self) -> str:
        return f"Keranjang {self.pembeli}: {len(self.items)} item"

    def __eq__(self, other) -> bool:
        if not isinstance(other, KeranjangBelanja):
            return False
        return self.items == other.items

k1 = KeranjangBelanja("Budi")
k1.tambah("Kopi")
k1.tambah("Gula")

k2 = KeranjangBelanja("Sari")
k2.tambah("Kopi")
k2.tambah("Gula")

print(str(k1))
print("Jumlah Item:", len(k1))
print("Apakah isi belanja sama:", k1 == k2)`}
  expectedOutput={`Keranjang Budi: 2 item\nJumlah Item: 2\nApakah isi belanja sama: True`}
/>

<CodePlayground
  client:load
  language="python"
  title="Latihan 5.6: Polimorfisme Arsitektur Objek"
  initialCode={`class Dokumen:
    def __init__(self, judul: str):
        self.judul = judul

    def render(self) -> str:
        raise NotImplementedError

class DokumenTeks(Dokumen):
    def render(self) -> str:
        return f"[TXT] {self.judul}.txt"

class DokumenPDF(Dokumen):
    def render(self) -> str:
        return f"[PDF] {self.judul}.pdf"

berkas: list[Dokumen] = [DokumenTeks("catatan_kuliah"), DokumenPDF("laporan_keuangan")]
for doc in berkas:
    print("Mengekspor:", doc.render())`}
  expectedOutput={`Mengekspor: [TXT] catatan_kuliah.txt\nMengekspor: [PDF] laporan_keuangan.pdf`}
