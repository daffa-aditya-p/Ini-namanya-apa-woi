## 2. KONSEP INTI: Descriptors, Data Numerik & Algoritma Pembelajaran

Berdasarkan dokumentasi resmi [docs.python.org: Descriptor HowTo Guide](https://docs.python.org/3/howto/descriptor.html) dan tutorial [W3Schools Python Machine Learning](https://www.w3schools.com/python/python_ml_linear_regression.asp), lima pilar penguasaan Level P5 mencakup:

1. **Descriptor Protocol (`__set_name__`, `__get__`, `__set__`):**
   - Kelas yang mengimplementasikan minimal satu dari method dunder descriptor. Mengontrol bagaimana atribut pada kelas pemilik (*owner class*) diakses dan dimutasi, menyimpan nilai secara aman di dalam `instance.__dict__`.
2. **Hook Metaprogramming: `__init_subclass__` (PEP 487):**
   - Menggantikan kebutuhan metaclass rumit (`type`) untuk 90% kasus pemodelan sistem. Dipanggil secara otomatis setiap kali kelas turunan baru didefinisikan, sangat ideal untuk registri plugin dan validasi skema.
3. **Statistik Data Science Murni:**
   - Menghitung tendensi sentral (*mean*), dispersi data (*variance* dan *standard deviation*), serta derajat asosiasi linear antar-variabel menggunakan Koefisien Korelasi Pearson ($r \in [-1, 1]$).
4. **Mini In-Memory REST Routing Engine:**
   - Pola routing bergaya FastAPI / Flask menggunakan dekorator fungsi parametrik yang memetakan tuple `(HTTP_METHOD, PATH)` ke fungsi handler yang bersangkutan.
5. **Machine Learning dari Nol: Ordinary Least Squares (OLS):**
   - Menentukan garis regresi terbaik `y = mx + b` secara eksak:
     `m = Σ((x_i - mean_x) * (y_i - mean_y)) / Σ((x_i - mean_x)²)` dan `b = mean_y - (m * mean_x)`

## 6. KESALAHAN UMUM (COMMON MISCONCEPTIONS)

1. **Menyimpan Nilai pada Objek Descriptor Sendiri (`self.nilai = value`):** Kesalahan paling fatal pemula saat membuat descriptor. Jika kamu menyimpan nilai di atribut `self.nilai` pada class descriptor, nilai tersebut akan **dibagi secara global** oleh seluruh instance kelas pemilik (*shared state*)! Nilai wajib disimpan pada dictionary objek instance pemanggil (`setattr(instance, self.nama_privat, value)`).
2. **Kelebihan Rekayasa Menggunakan Metaclass (`class M(type)`):** Banyak tutorial lama mengajarkan metaclass untuk validasi kelas. Sejak Python 3.6 (PEP 487), hook `__init_subclass__` jauh lebih bersih, mudah dibaca, dan tidak menimbulkan konflik metaclass (*metaclass conflict*).
3. **Pembagian dengan Nol pada Variansi Kosong (*Zero Division Error*):** Jika seluruh data sampel bernilai sama (misal `[5, 5, 5]`), nilai variansi bernilai 0. Menghitung korelasi pearson tanpa memeriksa nilai pembagi `penyebut == 0` akan memicu crash program.
4. **Ekstrapolasi Liar pada Model Machine Learning Linier:** Mengasumsikan bahwa hubungan linear berlaku tanpa batas untuk input di luar rentang data latih. Model linear sederhana rentan terhadap bias eksternal (*outlier sensitivity*) jika data tidak dibersihkan terlebih dahulu.
