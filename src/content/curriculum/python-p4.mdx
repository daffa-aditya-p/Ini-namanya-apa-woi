## Sub-bab 4.1: Definisi Fungsi & Parameter

Fungsi didefinisikan dengan kata kunci `def`, diikuti nama fungsi dan tanda kurung parameter `def nama_fungsi(parameter):`.

Python mendukung berbagai ragam parameter:
- **Argumen Posisi (*Positional Arguments*):** Nilai dicocokkan berdasarkan urutan deklarasi.
- **Nilai Bawaan (*Default Parameters*):** Mengisi nilai otomatis jika pemanggil tidak menyediakannya (`diskon=0.1`).
- **Argumen Fleksibel (`*args`):** Menampung sembarang banyaknya argumen posisi tambahan ke dalam sebuah **Tuple**.
- **Argumen Kata Kunci Fleksibel (`**kwargs`):** Menampung argumen `kunci=nilai` tambahan ke dalam sebuah **Dictionary**.

## Sub-bab 4.2: Nilai Balik & Scope

Fungsi mengembalikan hasil komputasi menggunakan kata kunci `return`. Jika kita mencantumkan beberapa nilai yang dipisahkan koma, Python secara otomatis mengemasnya (*packing*) ke dalam sebuah **Tuple**.

Variabel yang dibuat di dalam fungsi bersifat **Lokal** dan akan dibersihkan dari memori saat fungsi selesai dieksekusi. Python mengikuti hierarki pencarian nama **LEGB**:
1. **L (Local):** Dideklarasikan di dalam fungsi saat ini.
2. **E (Enclosing):** Di dalam fungsi pembungkus luar (pada fungsi bersarang).
3. **G (Global):** Di tingkat modul paling luar file.
4. **B (Built-in):** Fungsi bawaan Python seperti `len()`, `range()`, `print()`.

## Sub-bab 4.3: Lambda & Comprehensions

Untuk operasi sederhana yang hanya membutuhkan satu baris perhitungan sementara, gunakan fungsi anonim **Lambda** dengan sintaks `lambda parameter: ekspresi`. Lambda sangat sering digunakan sebagai parameter fungsi `sorted(..., key=lambda ...)`.

Selain itu, **Comprehensions** memungkinkan kamu mentransformasi dan memfilter koleksi secara deklaratif dalam satu baris ekspresif:
- **List Comprehension:** `[ekspresi for item in koleksi if kondisi]`
- **Dictionary Comprehension:** `{kunci: nilai for item in koleksi}`
