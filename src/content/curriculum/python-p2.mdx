## 2. KONSEP INTI: Koleksi Data Bawaan Python

Berdasarkan dokumentasi resmi [Python 3.12 Documentation: Data Structures](https://docs.python.org/3/tutorial/datastructures.html) dan tutorial [W3Schools Python Collections](https://www.w3schools.com/python/python_lists.asp), empat struktur koleksi inti Python memiliki karakteristik unik:
1. **List (`[]`):** Berurutan (*ordered*), dapat diubah (*mutable*), mengizinkan duplikat.
2. **Tuple (`()`):** Berurutan, tidak dapat diubah (*immutable*), hemat memori dan aman sebagai dictionary keys.
3. **Dictionary (`{key: value}`):** Pemetaan kunci-nilai hash map cepat, kunci wajib bertipe hashable/immutable.
4. **Set (`{}`):** Tidak berurutan, unik (tanpa duplikat), mendukung operasi matematika himpunan (irisan, gabungan).

## 6. KESALAHAN UMUM (COMMON MISCONCEPTIONS)

1. **Miskonsepsi Default Argumen List:** Mendefinisikan fungsi seperti `def simpan(item, daftar=[])`. Di Python, objek default argument dievaluasi hanya sekali saat modul dimuat, bukan setiap fungsi dipanggil. Menggunakan list mutable sebagai default argument akan membuat state akumulasi bocor antar-pemanggilan fungsi. Gunakan `daftar=None` lalu inisialisasi di dalam tubuh fungsi.
2. **Miskonsepsi Tuple Tunggal:** Menulis `t = (42)` tidak membuat tuple melainkan integer biasa. Untuk membuat tuple dengan satu elemen, koma wajib disertakan: `t = (42,)`.
3. **Miskonsepsi Modifikasi List Saat Loop:** Menghapus elemen dari list (`list.remove()` atau `del`) di tengah-tengah perulangan `for x in list`. Hal ini menyebabkan pergeseran indeks internal iterator dan elemen berikutnya terlewat. Gunakan list comprehension atau iterasi salinan `for x in list[:]`.
